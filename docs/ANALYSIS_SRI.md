# 분석: Shortcut reliance 검증 결과 (단계 4)

> 작성: 2026-11-18 · 대상: ResNet-18 / ResNet-50 × ρ 0.95 / 0.5 × seed 0–2 (모델 12개)
> 원본 결과: [`results/resnet18/`](../results/resnet18/README.md), [`results/resnet50/`](../results/resnet50/README.md) · 실험 설계: [`PROJECT_PLAN.md`](PROJECT_PLAN.md)

## 0. 결론 요약
- **모델 조작은 성공했다.** ρ만 바꿨는데 배경 의존도(SRI)가 ResNet-18에서 약 30배, ResNet-50에서 약 70배 차이 난다. seed 3개와 아키텍처 2개 모두에서 같은 방향이다. → 교수님 피드백 2("shortcut/clean 모델 차이를 사전에 객관적으로 검증")에 대한 근거.
- **지표들이 서로 일관된다.** SRI와 group gap이 거의 같은 값이고, worst-group acc는 SRI와 정확히 반대 순서다.
- **ResNet-50은 같은 ρ에서도 배경 의존이 더 약하다.** 그 결과 SRI가 네 수준(0.005 / 0.014 / 0.342 / 0.410)으로 나뉜다.
- 이 단계는 본 실험(baseline에 따른 XAI 평가 민감도) 전의 **준비 단계**다. 주 가설 H2는 단계 5–8에서 검증한다.

## 1. 무엇을 확인했나
본 실험은 "shortcut 의존도가 높은 모델일수록 masking baseline에 따라 faithfulness 평가가 더 흔들리는가"를 묻는다. 그러려면 먼저 **배경 의존도가 실제로 다른 모델들**이 있어야 한다. 학습 데이터의 상관 비율(ρ)을 다르게 설정했다고 해서 모델의 의존도가 반드시 그렇게 달라지는 것은 아니므로, 학습 후 test에서 직접 측정했다.

| 지표 | 정의 | 무엇을 보나 |
|---|---|---|
| avg acc | test 5,794장 전체 정확도 | 전반적 성능 |
| worst-group acc | 4개 그룹(landbird/waterbird × land/water 배경) 중 최저 정확도 | 가장 불리한 조건에서의 성능 |
| group gap | 평균(aligned 그룹 acc) − 평균(conflicting 그룹 acc) | 배경이 정답과 어긋날 때 정확도 손실 |
| **SRI** | 클래스별 \|평균 P(waterbird \| water 배경) − 평균 P(waterbird \| land 배경)\| 의 평균 | 같은 클래스에서 배경만 다를 때 예측 확률의 변화 |

test는 클래스 안에서 배경이 무작위 50:50으로 배정되어 있으므로, 같은 클래스 안 배경 그룹 간 차이를 배경의 효과로 해석한다.

## 3. 해석

### 3.1 모델 조작은 성공했다
- ResNet-18: SRI 0.014 → 0.410 (약 30배), ResNet-50: 0.005 → 0.342 (약 70배)
- shortcut 모델은 같은 클래스에서 배경만 바뀌어도 P(waterbird)가 평균 34–41%p 움직인다. clean은 0.5–1.4%p.
- seed 간 표준편차가 0.01 안팎이라 우연이 아니다.
- 두 ρ 조건은 train 크기(1,678장), 클래스 수(landbird 1,300 / waterbird 378), 학습 설정이 같고 이미지 923장을 공유한다. 따라서 **차이의 원인은 배경 조합 비율**로 좁힐 수 있다.

### 3.2 지표들이 서로 뒷받침한다
- **SRI ≈ group gap** (R18 shortcut 0.410 vs 0.413, R50 shortcut 0.342 vs 0.337). SRI는 예측 확률로, group gap은 정확도로 배경의 효과를 측정하는데 같은 크기가 나왔다. SRI를 의존도 지표로 쓰는 근거가 된다.
- SRI 순서(R50 clean < R18 clean < R50 shortcut < R18 shortcut)와 worst-group acc 순서(0.852 > 0.787 > 0.541 > 0.339)가 정확히 반대다.

### 3.3 ResNet-50은 배경에 덜 의존한다
- 같은 ρ = 0.95 데이터로 학습해도 SRI 0.342 vs 0.410, worst-group acc 0.541 vs 0.339
- clean 모델에서도 ResNet-50이 더 깨끗하다 (SRI 0.005 vs 0.014)
- 더 큰 사전학습 모델이 새의 특징을 더 잘 표현해서 배경에 덜 기대는 것으로 보인다. 다만 이 실험은 이를 검증하도록 설계되지 않았으므로 **관찰로만** 보고한다.

### 3.4 추가 관찰
| 관찰 | 해석 |
|---|---|
| clean 모델도 worst-group acc(0.79, 0.85)가 평균보다 낮다 | group gap은 0에 가깝다(0.016, 0.005). 배경이 아니라 waterbird가 적고(378 vs 1,300장) 어려운 클래스라서 생긴 차이로 보인다 |
| shortcut 모델의 worst-group acc가 0이 아니다 (0.34, 0.54) | 배경만 보는 것이 아니라 새도 일부 활용한다. 부분적 shortcut 의존이다 |
| shortcut 모델의 avg acc가 0.81–0.83 | test는 클래스 안에서 배경이 50:50이라 절반이 conflicting 이미지다. 여기서 많이 틀려 평균이 낮아진다 |
| 모든 모델의 train acc가 100% | shortcut 모델은 train의 소수 그룹(65장, 19장)을 외운 것이다. 그래서 의존도는 test로 판단했다 |

## 4. 한계
- **아키텍처와 의존도가 섞여 있다.** ResNet-50이 ResNet-18보다 의존도가 낮으므로, 아키텍처 간 차이를 SRI의 효과로 단정하기 어렵다.
- **ρ가 2단계뿐이다.** 아키텍처 덕분에 SRI가 네 수준으로 나뉘었지만, 경향을 주장하기에는 점이 적다.
- **SRI는 그룹 평균 비교다.** 같은 새를 배경만 바꿔 본 counterfactual이 아니라, 배경이 무작위로 배정된 그룹 간 비교다. test의 무작위 배정 덕분에 배경의 효과로 해석할 근거는 있지만, 개별 이미지 수준의 효과는 아니다.
- worst-group이 어느 그룹인지(예: waterbird + land)는 이 문서에서 정리하지 않았다. run별 `metrics.json`의 그룹별 정확도로 확인할 수 있다.

## 5. 다음 단계에 주는 의미
- **H2 분석 설계**: 같은 아키텍처 안에서 shortcut vs clean의 baseline 민감도를 비교하는 것을 **1순위**로 두고, SRI 네 수준에 따른 경향은 **보조 근거**로 쓴다. 회귀를 쓴다면 `민감도 ~ SRI + 아키텍처` 형태로 아키텍처를 통제한다.
- **XAI 평가 대상**: shortcut 모델은 conflicting 이미지를 많이 틀린다. 설명 대상은 모델이 예측한 클래스로 두고, 정답 여부는 따로 기록해 나눠 분석한다.
- **분포 이동 vs 마스킹 OOD 분리 (피드백 3)**: aligned/conflicting 그룹별로 민감도를 따로 계산하면, 분포 이동의 영향을 마스킹 OOD와 분리해서 볼 수 있다. shortcut 모델에서 두 그룹 간 차이가 크게 나타날 것으로 예상한다.
